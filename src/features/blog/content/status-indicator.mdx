## Features

- **Toast notification**: Shows Status Button as a Sonner toast
- **Animated states**: Loading → Success/Error with smooth transitions
- **Auto-dismiss**: Automatically dismisses after completion
- **6 color presets**: Default, Primary, Secondary, Success, Warning, Danger
- **5 radius options**: None, Small, Medium, Large, Full
- **Custom colors**: Use any Tailwind classes
- **Helper function**: Simple `showStatusIndicator()` API

## Usage

```tsx
import { showStatusIndicator } from "@/components/status-indicator";
import { TbCreditCard } from "react-icons/tb";

function PaymentButton() {
  const handlePayment = () => {
    showStatusIndicator({
      icon: <TbCreditCard className="size-5" />,
      label: "Pay $49.99",
      text: {
        loading: "Processing Payment",
        success: "Payment Complete",
        error: "Payment Failed",
      },
      onComplete: (success) => {
        if (success) {
          // Handle success
        }
      },
    });
  };

  return <button onClick={handlePayment}>Pay Now</button>;
}
```

## API

### `showStatusIndicator(options)`

Shows a status indicator toast and returns the toast ID.

| Option               | Type                                                                          | Default        | Description                       |
| -------------------- | ----------------------------------------------------------------------------- | -------------- | --------------------------------- |
| `icon`               | `ReactNode`                                                                   | Required       | Icon to display                   |
| `label`              | `string`                                                                      | Required       | Button label text                 |
| `text`               | `{ loading; success; error }`                                                 | Required       | State text                        |
| `color`              | `"default" \| "primary" \| "secondary" \| "success" \| "warning" \| "danger"` | `"default"`    | Color preset                      |
| `radius`             | `"none" \| "sm" \| "md" \| "lg" \| "full"`                                    | `"full"`       | Border radius                     |
| `colors`             | `{ loading?; success?; error? }`                                              | -              | Custom Tailwind classes per state |
| `className`          | `string`                                                                      | -              | Additional CSS classes            |
| `style`              | `CSSProperties`                                                               | -              | Inline styles                     |
| `simulationDuration` | `number`                                                                      | `2000`         | Duration before resolving (ms)    |
| `successRate`        | `number`                                                                      | `0.7`          | Probability of success (0-1)      |
| `onComplete`         | `(success: boolean) => void`                                                  | -              | Completion callback               |
| `position`           | `string`                                                                      | `"top-center"` | Toast position                    |
| `dismissDelay`       | `number`                                                                      | `2000`         | Delay before auto-dismiss (ms)    |

### `dismissStatusIndicator(id)`

Manually dismiss a status indicator by ID.
