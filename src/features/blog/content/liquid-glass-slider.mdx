## Usage

```tsx
import { LiquidGlassSlider } from "@/components/jyotirmoydas/liquid-glass-slider";
```

```tsx
<LiquidGlassSlider
  defaultValue={50}
  onChange={(value) => console.log("Value:", value)}
/>
```

## API Reference

### Value Control

| Prop           | Type                      | Default | Description                        |
| -------------- | ------------------------- | ------- | ---------------------------------- |
| `value`        | `number`                  |         | Controlled value of the slider.    |
| `defaultValue` | `number`                  | `10`    | Default value (uncontrolled mode). |
| `min`          | `number`                  | `0`     | Minimum value.                     |
| `max`          | `number`                  | `100`   | Maximum value.                     |
| `step`         | `number`                  | `1`     | Step size for value changes.       |
| `onChange`     | `(value: number) => void` |         | Callback when value changes.       |
| `onDragStart`  | `() => void`              |         | Callback when dragging starts.     |
| `onDragEnd`    | `() => void`              |         | Callback when dragging ends.       |

### Appearance

| Prop         | Type      | Default                    | Description                          |
| ------------ | --------- | -------------------------- | ------------------------------------ |
| `className`  | `string`  |                            | Additional CSS classes.              |
| `width`      | `number`  | `330`                      | Width of the slider track in pixels. |
| `fillColor`  | `string`  | `"#0377F7"`                | Color of the track fill (progress).  |
| `trackColor` | `string`  | `"#89898F66"`              | Color of the track background.       |
| `thumbColor` | `string`  | `"rgba(255, 255, 255, 1)"` | Color of the thumb.                  |
| `disabled`   | `boolean` | `false`                    | Whether the slider is disabled.      |

### Optical Parameters

Fine-tune the liquid glass refraction effect.

| Prop                 | Type     | Default | Description                                       |
| -------------------- | -------- | ------- | ------------------------------------------------- |
| `blur`               | `number` | `0`     | Blur level for the glass refraction effect.       |
| `specularOpacity`    | `number` | `0.4`   | Opacity of the specular highlight.                |
| `specularSaturation` | `number` | `7`     | Saturation multiplier for the specular highlight. |
| `refractionLevel`    | `number` | `1`     | Base refraction level (magnification intensity).  |
