## Usage

```tsx
import { LiquidGlassSearchbox } from "@/components/jyotirmoydas/liquid-glass-searchbox";
```

```tsx
const [query, setQuery] = useState("");

<LiquidGlassSearchbox
  value={query}
  onChange={setQuery}
  onClear={() => setQuery("")}
  placeholder="Search..."
/>;
```

## API Reference

### Input Control

| Prop              | Type                      | Default    | Description                                         |
| ----------------- | ------------------------- | ---------- | --------------------------------------------------- |
| `value`           | `string`                  |            | Controlled value of the searchbox.                  |
| `onChange`        | `(value: string) => void` |            | Callback when the input value changes.              |
| `onClear`         | `() => void`              |            | Callback when the clear button is clicked.          |
| `showClearButton` | `boolean`                 | `true`     | Whether to show the clear button when there's text. |
| `placeholder`     | `string`                  | `"Search"` | Placeholder text for the input.                     |
| `disabled`        | `boolean`                 | `false`    | Whether the searchbox is disabled.                  |

### Appearance

| Prop           | Type     | Default | Description                        |
| -------------- | -------- | ------- | ---------------------------------- |
| `className`    | `string` |         | Additional CSS classes.            |
| `width`        | `number` | `420`   | Width of the searchbox in pixels.  |
| `height`       | `number` | `56`    | Height of the searchbox in pixels. |
| `idleOpacity`  | `number` | `0.05`  | Background opacity when idle.      |
| `focusOpacity` | `number` | `0.2`   | Background opacity when focused.   |

### Optical Parameters

Fine-tune the liquid glass refraction effect.

| Prop                 | Type     | Default | Description                                       |
| -------------------- | -------- | ------- | ------------------------------------------------- |
| `blur`               | `number` | `1`     | Blur level for the glass refraction effect.       |
| `specularOpacity`    | `number` | `0.2`   | Opacity of the specular highlight.                |
| `specularSaturation` | `number` | `4`     | Saturation multiplier for the specular highlight. |
| `refractionLevel`    | `number` | `0.7`   | Base refraction level (magnification intensity).  |
