## API Reference

### Callbacks

Event handlers triggered during state transitions.

| Prop       | Type         | Description                                              |
| ---------- | ------------ | -------------------------------------------------------- |
| `onUnlock` | `() => void` | Callback triggered when the slider reaches ON position.  |
| `onLock`   | `() => void` | Callback triggered when the slider reaches OFF position. |

### Behavior

Control the switch's initial state and feedback mechanisms.

| Prop             | Type      | Default      | Description                                     |
| ---------------- | --------- | ------------ | ----------------------------------------------- |
| `defaultChecked` | `boolean` | `false`      | Initial state of the switch.                    |
| `soundEnabled`   | `boolean` | `true`       | Whether to play the unlock sound effect.        |
| `toastEnabled`   | `boolean` | `true`       | Whether to show a toast notification on unlock. |
| `toastMessage`   | `string`  | `"Unlocked"` | Custom message to display in the unlock toast.  |
| `disabled`       | `boolean` | `false`      | Whether the switch is disabled.                 |

### Appearance

Customize the visual appearance of the switch.

| Prop            | Type     | Default                    | Description                             |
| --------------- | -------- | -------------------------- | --------------------------------------- |
| `className`     | `string` |                            | Additional CSS classes to apply.        |
| `thumbColor`    | `string` | `"rgba(255, 255, 255, 1)"` | Color of the thumb/handle.              |
| `trackColorOff` | `string` | `"#94949F77"`              | Background color of the track when OFF. |
| `trackColorOn`  | `string` | `"#3BBF4EEE"`              | Background color of the track when ON.  |

### Optical Parameters

Fine-tune the liquid glass refraction effect. These parameters control the SVG filter that creates the glass-like appearance.

| Prop                 | Type     | Default | Description                                       |
| -------------------- | -------- | ------- | ------------------------------------------------- |
| `blur`               | `number` | `0.2`   | Blur level for the glass refraction effect.       |
| `specularOpacity`    | `number` | `0.5`   | Opacity of the specular highlight.                |
| `specularSaturation` | `number` | `6`     | Saturation multiplier for the specular highlight. |
| `refractionLevel`    | `number` | `1`     | Base refraction level (magnification intensity).  |
