# Jyotirmoy Das

A simple CLI wrapper for adding components from [jyotimoydas.in](https://jyotimoydas.in/components) component registry using [shadcn](https://ui.shadcn.com/docs/cli).

## Usage

```bash
npx jyotirmoy add [components...]
```

### Example

```bash
npx jyotirmoy add liquid-glass-slider status-button
```

This will install the `liquid-glass-slider` and `status-button` components from the registry.
